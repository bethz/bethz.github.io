"We're going to build an AI agent platform."

I hear this in every enterprise meeting. Ambitious. Exciting. And almost always wrong as a starting point.

The teams that actually ship production AI agents start differently. They start with one decision.

Not a platform. Not a framework. Not a grand architecture. One decision, made by one person, that could be made better with one agent.

My ICON talk this year boiled it down:
- Start with one decision
- One workflow
- One agent
- One measurable win

Then scale.

Why this works:
- You learn what "production-grade" actually means for your org
- You discover the governance questions before they're emergencies
- You build trust with stakeholders through evidence, not promises
- You create a template that scales, not a prototype that dies

Why "platform first" fails:
- Nobody agrees on requirements because nobody's built one yet
- The platform serves hypothetical use cases
- Six months in, you have infrastructure and zero value delivered

The fastest path to 50 agents isn't building 50 agents. It's proving one works, then letting demand pull the next 49 into existence.

One agent. One decision. One win. Then repeat.
